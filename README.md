## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 段落で、`段落ID<TAB>本文` の形です。原本の行の切れ目は ⏎ で示しています（⏎ は改行の印で、本文の字ではありません）。50段落ごとにファイルを分けています（3ファイル）。 |
| `shiki-hitobito-ni-kotau.json` | 本文・底本・作品の説明をまとめた JSON（訳は入れず、`yaku/` だけに置いています）。段落ごとに原本のコマ番号があります。振り仮名（`ruby`）もここにあります。 |

段落ID（例: `shiki-hitobito-ni-kotau-000001`）は、本文を直しても変わりません。データの形は雲居の文庫の作品リポジトリと同じです。

## 誤りを見つけたら

受け取った修正は、底本と照らして確かめてから取り込みます。
